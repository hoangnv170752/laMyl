# laMyl

> **sounds good. feels better.**

A macOS menu bar app that plays satisfying mechanical keyboard sounds as you type.

## Overview

laMyl is an audio application for computer users, inspired by the mechanical keyboard typing experience. Rather than simply simulating keyboard sounds, laMyl creates a pleasant working soundscape that helps users feel focused, relaxed, and inspired.

## Features

- Mechanical keyboard sounds while typing on any Mac app
- Multiple sound profiles (Deep Thock, Soft Linear, Creamy, etc.)
- Low Volume Boost for clear audio at low system volume
- Menu bar app with quick access controls
- Privacy-first: keystrokes stay on your Mac
